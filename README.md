## Timetables to PDF converter

Tool for converting FINKI's current timetables to pdf format. You can also convert previous timetables by editing the `index.mjs` file.

## Usage

- You'll need Node.js installed v18 or above
- Install all dependencies: `npm install`
- Run the project: `node .` or `npm run start`
